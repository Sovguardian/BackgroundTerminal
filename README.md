# 🖥️ BackgroundTerminal

A transparent, widget-like terminal window for Windows, built with **C#**, **WPF**, and **.NET 9**.

---

## ✨ Features

- 📜 **Terminal with custom commands** (`help` for full command list)
- ⏰ **Large clock widget**
- ☁️ **Weather display**
- ⚙️ **System performance monitor**
- 📰 **Random news from DTF and Shikimori**
- 🖥️ **Neofetch-style system info**
- ✨ **Quotes widget with custom quote support**

## 🚀 Installation

1. Download the latest release from [Releases](https://github.com/Sovguardian/BackgroundTerminal/releases)
2. Run `BackgroundTerminal.exe`
3. If you don't have **.NET 9 Runtime** installed — the app will prompt you to get it.

## 🛠️ Commands

Type `help` inside the terminal window to see available commands.
